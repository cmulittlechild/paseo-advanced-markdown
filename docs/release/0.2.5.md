# Advanced Markdown 0.2.5

Fixes formulas appearing as raw LaTeX when a local source-file link is present
in the same message. The plugin now renders supported local links alongside
formulas and Mermaid diagrams instead of handing the entire message back to
Paseo's renderer.

- Clicking a local link opens a read-only preview on the selected host, relative
  to the conversation's working directory when needed.
- Supports relative and absolute paths, `file://` URLs, reference links, and
  line anchors such as `:120` and `#L10-L20`.
- Shows line numbers and offers path/source copying. Missing, unreadable, binary,
  oversized, or out-of-range files return a readable error with retry.
- Reads files only on request. Previews are limited to regular UTF-8 files up
  to 1 MiB, showing at most 200 lines / 32 KiB around the requested line.
- Adds parser, link, file-preview, corpus, and streamed-link regression coverage.

The preview uses public plugin APIs; it does not open a native workspace file tab.
Inline images and unsupported link schemes still use Paseo's renderer. Math
asset startup recovery and the supported range `>=0.8.0 <0.11.0` are retained.

The recorded web validation covers the official Paseo 0.10.1 client at desktop
and compact widths, including line anchors, clipboard contents, and missing-file
errors. This is not iOS/Android device acceptance. See the
[validation and SDK limits](../qa/math-reading-gaps.md).

Install from Git:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.2.5
```

For an existing Git installation, if the CLI supports `plugin update --ref`:

```bash
paseo plugin update advanced-markdown --ref v0.2.5
```

The npm release is `paseo-advanced-markdown@0.2.5`. Use v0.2.4 to roll back on
the same supported Paseo versions; it does not include the file-link fix.
