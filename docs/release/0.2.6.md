# Advanced Markdown 0.2.6

Extends the Paseo app and daemon requirement to `>=0.8.0 <0.12.0`, allowing
the entire 0.11.x series while retaining support for 0.8–0.10. Paseo compares
prereleases using their stable core: 0.11 prereleases are accepted, and 0.12
prereleases and later are excluded.

Validation on 2026-10-05 used the official `0.11.0-beta.3` compiler, SDK,
daemon, and packaged web client. This was the newest published 0.11 release;
stable `0.11.0` was not yet available. Future 0.11 patches are admitted by the
version policy, not claimed as individually tested. No rendering implementation
or production daemon restart is part of this update.

- Both app and daemon version gates cover accepted 0.11 versions and rejected
  0.12 versions. CI adds 0.11.0-beta.3 to the existing compatibility matrix.
- The official compiler/SDK smoke passed formula and Mermaid rendering,
  registration, local-link handling, and invalid-input fallbacks. Its projection
  and streaming fixtures remain pinned to 0.8.0.
- An isolated official 0.11 daemon and web client rendered inline/display math
  and Mermaid at 1280px and 390px without page overflow or JavaScript errors.
  Local file previews, line anchors, exact source copying, and missing-file
  retries passed. Formula/diagram viewers passed opening, zoom/fit, Preview/Source
  switching, exact LaTeX/Mermaid/Markdown copying, and closing at both widths.
- The isolated npm installation passed compilation, real PNG rendering, package
  relocation, empty-cache startup, and corrupt-WASM/missing-font recovery
  without the original asset files. Its production dependency audit passed.

Native iOS/Android UI was not tested in this release. The 0.8.0 development SDK
baseline is retained; the new runtime is installed separately for validation.

Install from Git:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.2.6
```

For an existing Git installation with `plugin update --ref` support:

```bash
paseo plugin update advanced-markdown --ref v0.2.6
```

The npm release is `paseo-advanced-markdown@0.2.6`. Rollback to v0.2.5 requires
Paseo 0.8–0.10; older plugin releases do not accept Paseo 0.11.
