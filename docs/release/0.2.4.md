# Advanced Markdown 0.2.4

Extends the Paseo app and daemon requirement from `>=0.8.0 <0.10.0` to
`>=0.8.0 <0.11.0`, allowing Paseo 0.10.x to load the plugin. The minimum supported
version stays at 0.8.0. Paseo normalizes prereleases to their stable core for this
check: 0.10 prereleases are accepted, while 0.11 prereleases and later are excluded.

The rendering code, viewer, settings, and v0.2.3 offline asset recovery are unchanged.
Development dependencies remain pinned to the 0.8.0 SDK. CI adds the published
0.10.1 compiler and SDK alongside the existing 0.8.0 and 0.9.0-beta.2 checks.
Version-gate tests cover both app and daemon, including the upper-bound rejection.
The compatibility harness checks compilation, registration, formula/Mermaid PNGs,
and npm startup recovery; it does not establish device UI acceptance on every
version in the range.

Install from Git:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.2.4
```

For an existing Git installation, if the CLI supports `plugin update --ref`:

```bash
paseo plugin update advanced-markdown --ref v0.2.4
```

The npm release is `paseo-advanced-markdown@0.2.4`. On Paseo 0.8/0.9, v0.2.3
remains a rollback option; it cannot load on Paseo 0.10 due to its older requirement.
